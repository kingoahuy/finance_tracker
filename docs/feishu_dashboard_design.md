# 飞书财务看板设计

## 1. 数据模型

看板采用两张表，不把所有逻辑塞进交易流水：

| 数据表 | 粒度 | 适合回答的问题 |
| --- | --- | --- |
| 数据表 | 一笔交易一行 | 钱花到哪里、哪些是刚需、固定支出、标签与明细 |
| 看板日指标 | 一个自然日一行 | MTD/YTD、日均/月均、预算进度、趋势与预测 |

SQLite 仍是唯一主数据源，飞书是分析镜像。`看板日指标`由本地流水重新计算，不在飞书手工维护。

## 2. 指标口径

- MTD：当前快照日期所在月份，从月初累计到该日期。
- MTD 日均：MTD 金额除以本月已过自然日，零交易日也进入分母。
- YTD：当前快照日期所在年份，从年初累计到该日期。
- YTD 日均：YTD 金额除以本年已过自然日。
- YTD 月均：YTD 金额除以本年已过月份数，当前未结束月份也计入。
- 储蓄率：`(收入 - 支出) / 收入`；没有收入时显示 0。
- 主收入、支出和净额：只统计有效流水，并排除“个人垫付”。垫付支出、回款和余额单独展示。
- 餐补消费：仅统计支出流水中明确出现“餐补、餐卡、饭卡、餐券”等支付证据的金额；餐补到账和普通餐饮不计入。
- 餐补消费占比：`餐补消费金额 / 看板支出`；分母同样排除个人垫付。当前同时提供 MTD 与 YTD 口径。
- 预算进度偏差：`MTD预算使用率 - 月度时间进度`。正数表示花钱速度快于时间进度。
- 预计月末支出：`MTD日均支出 × 当月自然日数`，用于节奏预警，不是严格预测模型。

`MTD口径完整`与`YTD口径完整`用于提示历史数据是否从月初/年初完整覆盖。做跨期对比时建议筛选为“是”。

## 3. 交易底表的看板字段

新增字段均可直接“求和”，不需要在图表里重复写过滤公式：

| 字段 | 含义 | 推荐用途 |
| --- | --- | --- |
| 看板收入 | 有效、非个人垫付的收入 | 收入来源、月度收入 |
| 看板支出 | 有效、非个人垫付的支出 | 分类、标签、趋势 |
| 看板净额 | 看板收入减看板支出 | 收支结余 |
| 刚需支出 / 非刚需支出 | 看板支出按刚需拆分 | 消费质量 |
| 固定支出 / 变动支出 | 看板支出按固定性拆分 | 支出弹性 |
| 是否个人垫付 | 个人垫付标记 | 垫付明细与审计 |
| 是否使用餐补 | 明确使用餐补支付的支出标记 | 餐补消费明细筛选 |
| 餐补消费金额 | 有效、非个人垫付且明确使用餐补的支出 | 餐补消费额及占比 |

原来的`收入金额`、`支出金额`、`净额`继续保留，作为原始交易口径与审计字段。

## 4. 推荐看板布局

### 第一屏：财务驾驶舱

数据源选择`看板日指标`，所有指标卡筛选`是否最新 = 是`：

1. MTD 收入
2. MTD 支出
3. MTD 净额
4. MTD 日均支出
5. 预计月末支出
6. 预算剩余

第二排放置 YTD 收入、YTD 支出、YTD 净额、YTD 月均收入、YTD 月均支出、YTD 储蓄率。

餐补指标建议增加四张卡片：`MTD餐补消费`、`MTD餐补消费占比`、`YTD餐补消费`、`YTD餐补消费占比`。占比字段已经按百分数生成，飞书中直接展示即可。

预算预警建议用三个并列指标：`MTD预算使用率`、`月度时间进度`、`预算进度偏差`。偏差大于 0 时，表示支出进度快于时间进度。

### 第二屏：趋势与节奏

- 每日支出趋势：维度`日期`，指标`当日支出`，叠加`近7日日均支出`和`近30日日均支出`。
- 月度收支趋势：筛选`是否月度观察点 = 是`，维度`年-月`，指标`MTD收入`和`MTD支出`。
- 月度结余趋势：同样筛选月度观察点，指标`MTD净额`。
- 支出预测：维度`日期`，指标`预计月末支出`与`月预算`。

### 第三屏：支出结构

数据源选择交易`数据表`：

- 分类支出占比：维度`分类`，指标求和`看板支出`。
- 刚需/非刚需：指标求和`刚需支出`、`非刚需支出`。
- 固定/变动：指标求和`固定支出`、`变动支出`。
- 标签排行：维度`标签`或`标签文本`，指标求和`看板支出`。
- 餐补消费结构：筛选`是否使用餐补 = 是`，维度`分类`或`标签`，指标求和`餐补消费金额`。
- 金额区间：维度`金额区间`，指标求和`看板支出`，辅助识别小额高频消费。

### 第四屏：现金与垫付

数据源选择`看板日指标`：

- 垫付余额：筛选`是否最新 = 是`，指标`垫付余额`。
- 垫付变化：维度`日期`，指标`当日垫付支出`和`当日垫付回款`。
- 垫付明细：回到交易`数据表`，筛选`是否个人垫付 = 是`。

## 5. 推荐筛选器

- 全局日期范围：用于趋势和结构图；不要让它覆盖“是否最新”的 MTD/YTD 指标卡。
- 年-月：结构分析的首选筛选器。
- 分类：定位主要支出驱动。
- 是否刚需、是否固定：用于消费质量和可压缩空间分析。
- 标签：用于旅行、学习、项目等专项复盘。

避免把过多筛选器放在第一屏。成熟驾驶舱的默认视图应当无需点击就能回答“本月花了多少、速度是否过快、今年总体是否健康”。

## 6. 同步命令

```powershell
# 批量创建并回填交易底表的看板安全字段
.\.venv\Scripts\python.exe -m finance_tracker.bitable_sync --sync-dashboard-fields

# 创建/刷新每日指标表
.\.venv\Scripts\python.exe -m finance_tracker.bitable_sync --sync-dashboard-daily
```

以后新增、修改或删除交易时，交易同步完成后会从受影响日期开始刷新每日指标；跨入新的一天后，调度器也会补建当天的零交易快照。
